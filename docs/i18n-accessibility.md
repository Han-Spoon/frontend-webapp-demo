# 다국어와 접근성

언어: ko, en, ar, zh-CN, ja, zh-TW, es. `locales.ts`의 LANGUAGE_CODES/LOCALES/OPTIONS를 원본으로 사용한다. 기존 서버 언어 enum은 ko/en/ar라서 나머지는 로컬 선택을 보존하고 서버 요청에 fallback한다.

## 번역

번역 구조: ko/en/ar는 호출부에 직접(`t(ko, en, ar)`·`{ ko, en, ar }`), zh-CN/ja/zh-TW/es는 `src/app/i18n/<언어>.ts` 사전(한국어 원문이 키)에서 찾고 없으면 영어. 사전은 그 언어를 고를 때만 받는다(ko·en·ar 사용자는 받지 않음). 받는 동안 이전 언어를 유지하고, 저장된 언어가 4개 언어면 첫 화면을 그리기 전에 받는다. 받기 실패 시 그 언어로 바꾸고 사전 문구만 영어 fallback. 한국어 문구를 고치면 키가 끊기므로 사전도 함께 고친다. `check-demo`가 코드에 없는 사전 키와 언어별 누락 수 변화를 실패로 잡는다.

2026-11-22 번역 현황(화면 한국어 문구 657개 기준, 누락 = 영어 표시): zh-CN·ja·es 각 275개(42%), zh-TW 152개(23%). 번역을 채우면 `check-demo`의 `I18N_MISSING_BASELINE`과 이 숫자를 함께 낮춘다. 사전 549개 키(zh-TW 549, zh-CN·ja·es 각 258). 코드에서 사라진 키 112개 삭제(git 기록에 보존), 끝 문장부호만 달라 끊긴 키 1개는 코드 문구로 옮겨 zh-CN·ja·es 복구.

2026-11-21 분석 중·다시 찍기·실패: 새로 쓴 문구는 7개 언어(ko/en/ar/zh-CN/ja/zh-TW/es) 임시 번역을 컴포넌트에 직접 둔다. 서버의 다시 찍기 이유·제안(`retakeReasons`·`retakeSuggestions`)은 번역 없는 한국어라 한국어 사용자에게만 `lang="ko"`로 보여 주고, 다른 언어에는 번역된 기본 촬영 팁을 보여 준다. 30초 지연 안내는 `role="status"`로 읽힌다. 전문 번역 검수는 후속 대상이다.

2026-11-14 약관·온보딩: 약관 제어 문구는 7개 언어를 제공한다. 법적 효력을 가지는 4개 약관 본문은 현재 한국어 원문만 제공하며, 다른 언어 화면에는 번역 미완료를 명시한다. 법무 검토를 거친 번역을 공개하기 전까지 본문을 임의 자동 번역하지 않는다. 온보딩의 기존 7개 언어 선택과 아랍어 RTL을 유지한다. 약관의 필수 동의 버튼은 실제 스크롤 끝에 도달해야 켜지고 키보드로도 조작할 수 있다.

시연 동선: 「로그인 없이 시연하기」는 한국어·영어·아랍어 전용 문구와 나머지 언어의 영어 fallback을 사용한다. 데모 약관의 서버 미저장 안내는 7개 언어로 제공한다.

2026-11-14 결과·찜: 새 결과 머리·카드·저장한 메뉴의 동작 문구는 ko/en/ar를 제공하고 나머지 4개 언어는 기존 `createTranslator` fallback을 사용한다. 가격은 `dir=ltr`, 아랍어 화살표는 RTL 방향을 유지한다. 메뉴명과 판정은 서버·시연 원자료를 사용하며 새 번역을 임의 생성하지 않는다. 전문 번역은 후속 검수 대상이다.

2026-11-14 식당 후기·촬영/분석: 새 후기 시트, 마이페이지 목록, 신고 사유와 촬영·분석 상태 문구는 ko/en/ar를 제공하며 zh-CN/ja/zh-TW/es는 영어 fallback이다. 후기의 사용자 입력과 실제 식당명은 번역하지 않는다. 시트는 아랍어 RTL을 지정한다. 후기 항목 ID의 사람이 읽을 수 있는 다국어 라벨과 네 언어의 전문 번역은 후속 검수 대상이다.

기존 createTranslator와 translateText를 사용한다. 새 화면은 ko/en/ar 문구가 있으며 신규 핵심 컨트롤은 간체·일본어·번체·스페인어 임시 번역을 추가한다. 새 큐레이션 12편은 ko/en/ar 본문을 제공하고 나머지 언어의 장문은 영어 fallback이다. 최종 번역 완료로 표현하지 않는다.

식당은 한글 원명과 영문 별칭을 보유한다. 모든 상호를 번역해서 별개 식당으로 저장하지 않는다. 검색은 canonical ID에 연결된 alias 인덱스를 향후 확장한다. 데모 검색은 이름과 지역의 부분 일치다.

2026-09-14 발견 개편: 랭킹 분류·지도 위치 안내·큐레이션 공통 UI는 ko/en/ar 문구를 제공한다. 새 파트너 레시피의 이름·재료·판정 설명은 ko/en이며 다른 언어에는 기존 영어 fallback을 적용한다. 7개 언어 선택과 기존 번역은 유지하지만 신규 문구의 전체 언어 번역 완료를 뜻하지 않는다.

2026-09-15 홈 추천: 랭킹은 제거했다. 새 추천 UI는 ko/en/ar와 나머지 언어의 영어 fallback을 제공한다. 식당명·업종·주소는 API 원문이다. RTL 스크롤/화살표 방향, 모션 감소, 키보드 초점과 44px 컨트롤을 유지한다.

분식 촬영 fixture의 메뉴 설명·근거·질문은 ko/en이며 그 외 언어는 영어 fallback이다. 새 근거 UI의 컨트롤은 ko/en/ar를 제공한다. ‘매운 음식’, ‘알코올’ 프로필 라벨은 7개 언어에서 제외 표현 없이 표시한다.

2026-09-15 번체 중국어 시연 검수: `zh-TW`는 랜딩부터 로그인, 온보딩, 홈, 지도, 입점 식당 메뉴, 스캔·분석·결과, 직원 소통, 기록, 마이페이지, 카드, 큐레이션 목록·상세까지 전용 대만식 UI 문구를 제공한다. 13개 분식 촬영 fixture와 12개 추가 큐레이션 본문도 번체 원고를 사용하며 `zh-CN` 또는 영어 본문으로 대체하지 않는다. 한국어 원메뉴명, 직원에게 직접 보여 주는 한국어 문장, 브랜드명과 로마자 발음은 의도적으로 함께 표시한다. 라이브 API의 고유 식당명·메뉴명·판정 설명은 서버가 해당 언어 값을 제공하지 않으면 원문/영문을 유지한다.

iPhone 홈 화면 추가용 아이콘은 `public/apple-touch-icon.png`, `public/icon-192.png`, `public/icon-512.png`를 사용한다. `manifest.webmanifest`의 기본 시작 경로는 운영 진입점 `/`이며 데모 쿼리를 강제하지 않는다. 오프라인 캐시나 Service Worker는 이 범위에 포함하지 않는다.

## RTL·접근성

ar에서 html dir=rtl. 포털 바텀시트는 자체 dir도 지정한다. 지도 좌표는 방향에 따라 뒤집지 않고 글자와 컨트롤을 RTL로 배치한다. 가격은 독립적인 ltr 영역에서 유지한다.

Radix Dialog 기반 시트는 제목·설명, 포커스 이동/복귀, Escape 닫기, 배경 차단을 제공한다. 하트/핀/필터는 aria-label 또는 aria-pressed를 제공한다. 라디오 후기는 fieldset/legend로 묶는다. 상태는 색상만으로 구분하지 않고 텍스트와 아이콘을 함께 쓴다.

320/390/430px, 긴 번역, 확대, 키보드 포커스, reduced-motion을 검증한다. 장문 영어 fallback은 RTL에서도 섞일 수 있으므로 최종 아랍어/타 언어 편집 검토가 필요하다.
