## 지도·카드 진입 실패 원인

기존 열린 탭은 `index-BZhRCMmy.js`에서 이전 청크 `RestaurantMapScreen-BAGQ_DK6.js`, `CardsScreen-DpHYlvQz.js`를 요청했다. 개발자도구에 `Failed to fetch dynamically imported module` 및 JS 요청의 응답 MIME이 `text/html`이라는 오류가 있었다. 지도 진입과 다시 시도 실패를 재현했다. 지도 페이지 브라우저 새로고침 이후 정상 지도 표시, 카드 URL 새 진입 이후 정상 카드 표시를 확인했다.

`vercel.json`의 전체 경로 → index.html rewrite와 이전 청크 URL의 HTML 응답이 일치한다. 원인은 배포 교체 후 기존 탭의 코드와 최신 정적 파일 사이 버전 불일치로 판단한다. 단순 새로고침은 현재 사용자 임시 복구이고 영구 수정은 아니다. 촬영/분석 청크도 같은 오류가 Console에 남아 있었다.

## 확인한 범위

- 홈: 18개 지역 버튼 → 각 지역 식당 카드 6개 표시, 추천 다음 버튼, 전체 지도, 마이페이지 진입.
- 지도: 새로고침 복구, 음식 종류 필터, 거리순 선택, 목록 펼침, 식당 상세/후기 실패/재시도, 식당 선택 후 촬영 진입.
- 큐레이션: 22개 상세 페이지의 제목·본문 렌더링 및 뒤로 이동, 카테고리 필터, 검색/빈 검색, 식당 후보 찾기·지도 이동.
- 카드: 개인화 질문을 포함한 기본 문장 6개 각각 열기·닫기, 문장 목록 접기, 저장 카드 빈 상태, 스캔 이동. 음성 버튼 클릭은 확인했으나 실제 청취 품질은 판정하지 않음.
- 촬영: 화면 표시, 식당 선택/이름 검색/빈 결과/식당 없이 계속, 기존 기록 열기, 제목 편집 빈 입력 저장 비활성·취소.
- 결과: 기존 기록 표시, 안전 필터, 근거 펼치기, 식단 전달 항목 선택·질문, 직원 질문 카드, 주문/제외 요청 전환, 기록 수정 시트.
- 마이페이지: 프로필·스캔 기록·설정 탭, 언어·나라·식단 편집 화면, 나라 검색 빈 결과, 저장 음식·내 후기 오류 화면, 동의 편집·마케팅 본문·뒤로 이동.
- 별도 `/history` 페이지: 기록 목록·수정·삭제 버튼 렌더링.
- 후기 작성: 메뉴 이름 추가·선택에 따른 입력 질문 및 저장 가능 상태 확인, 제출하지 않고 취소.

## 미검증/제한

모든 버튼의 실제 저장 성공까지 검증한 것은 아니다. 계정 설정·동의 변경, 로그아웃·탈퇴, 기존 기록 삭제/수정 저장, 음식/가게/카드 저장·해제, 공개 후기 제출·수정·삭제·신고, 직원 사실 답변 제출은 실행하지 않았다. 새 메뉴판 이미지가 없어 업로드 → AI 분석 → 새 결과의 실서버 전 과정도 실행하지 않았다. 신규 가입/온보딩, 7개 언어 전체 렌더링, 모바일 실기기 카메라·위치 거부·오프라인은 별도 검증이 필요하다.

지도 식당 상세는 처음 일부 클릭에서 유지되지 않았으나 재검사에서는 정상 열렸다. 브라우저 사용 중 사용자 조작도 감지되었으므로 상세 버튼 고장으로 확정하지 않는다. 이후 재현 환경을 분리해 확인할 항목이다.

사용자 Chrome은 마지막에 `/home`으로 복귀했다. 임시 후기 입력은 취소했고 서버 데이터 변경 요청을 제출하지 않았다.
