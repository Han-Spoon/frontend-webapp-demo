# 한스푼 브랜드 가이드

> Version 0.2 · 2026-11 한스푼 새 테마(민트 프레시). 0.1은 AI·SW중심대학 우수작품경진대회 UI/UX 리뉴얼

## 1. 브랜드 정의

### 브랜드명

- 국문: **한스푼**
- 영문: **Han Spoon**
- 코드·저장소 표기는 기존 명칭을 유지하되, 사용자 화면에서는 위 표기를 일관되게 사용한다.

### 지원 언어

- 한국어
- 영어
- 아랍어
- 중국어(간체)
- 일본어
- 중국어(번체)
- 스페인어

### 브랜드 한 문장

**낯선 한국 메뉴도 안심하고 발견하도록 돕는 가장 친근한 여행 식탁 가이드**

### 브랜드 철학

한스푼은 언어와 식문화의 차이 때문에 한국 음식을 고르는 일이 불안한 경험이 되지 않아야 한다고 믿는다. 메뉴의 의미와 식이 위험 정보를 이해하기 쉽게 전하고, 필요한 말을 식당에 정확히 전달할 수 있도록 도와 사용자가 자신의 기준에 맞는 음식을 안심하고 발견하게 한다.

### 브랜드 약속

**낯선 메뉴도, 안심하고 한 스푼.**

### 핵심 가치

1. **안심** — 알레르기·종교·채식 등 사용자의 식이 기준을 명확하고 신중하게 안내한다.
2. **발견** — 제한 사항만 보여주는 데 그치지 않고, 먹을 수 있는 한국 음식의 즐거움을 넓힌다.
3. **연결** — 사용자와 식당 사이의 언어 장벽을 낮추고 필요한 의사소통을 돕는다.

## 2. 브랜드 성격

한스푼은 딱딱한 번역 도구나 경고 중심의 건강 앱이 아니다. 믿을 수 있는 정보를 주면서도 새로운 음식을 함께 찾아주는 친근한 한국 여행 동반자다.

| 성격 | 표현 방식 | 피해야 할 방식 |
| --- | --- | --- |
| 믿음직한 | 근거와 상태를 명확히 설명한다 | 과장된 안전 보장, 모호한 단정 |
| 친근한 | 짧고 쉬운 말, 부드러운 존댓말을 쓴다 | 지나친 유행어, 유아적인 말투 |
| 호기심 많은 | 먹을 수 있는 메뉴와 새로운 맛을 제안한다 | 위험·제한 정보만 강조 |
| 세심한 | 문화·종교·식이 차이를 존중한다 | 특정 문화를 고정관념으로 표현 |

## 3. 핵심 메시지

### 대표 슬로건

**낯선 메뉴도, 안심하고 한 스푼.**

### 보조 문구 후보

- 한국의 맛을 이해하는 가장 쉬운 방법
- 안심은 더하고, 낯섦은 덜고
- 나에게 맞는 한국 음식을 발견해 보세요
- 메뉴판 한 장으로 시작하는 맛있는 한국 여행

### 메시지 우선순위

1. 사용자의 식이 기준에 맞는지 이해할 수 있다.
2. 한국어 메뉴가 무엇인지 쉽게 알 수 있다.
3. 먹고 싶은 메뉴를 발견할 수 있다.
4. 필요한 내용을 식당에 정확히 전달할 수 있다.

## 4. 보이스 앤 톤

### 기본 원칙

- 한 문장에는 하나의 행동이나 정보만 담는다.
- 사용자가 다음에 무엇을 하면 되는지 먼저 알려준다.
- 위험을 과장해 겁주지 않고, 이유와 대응 방법을 함께 보여준다.
- 번역투보다 여행 중 실제로 이해하기 쉬운 자연스러운 문장을 사용한다.
- 한국어·영어·아랍어·중국어(간체·번체)·일본어·스페인어에서 의미와 친절함의 수준을 동일하게 유지한다.

| 오류 | 사진이 흐려 메뉴를 읽기 어려워요. 다시 찍어볼까요? | OCR 처리 실패 |
| 대기 | 메뉴 속 재료를 꼼꼼히 살펴보고 있어요 | 분석 중입니다 |

- 글자 로고: `src/assets/brand/han-spoon-logo.svg` (글자 + 숟가락, 로고 초록 `#176B4D` · 숟가락 주황 `#F4773B`)
- 심볼: `src/assets/brand/han-spoon-symbol.svg` (그릇 지붕 + 숟가락). 파비콘 `public/han-spoon-logo-favicon.svg`와 앱 아이콘(`apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, 흰 바탕)은 이 심볼에서 만든다.

### 사용 원칙

- **한 화면에 로고는 한 번만** 쓴다. 로고 또는 상단 영역의 옅은 심볼 워터마크(불투명도 0.14) 중 하나.
- 색을 바꾸거나 늘이지 않는다. 지도 핀에는 로고를 넣지 않는다.
- 흰 바탕 · 민트 바탕 위에 쓴다.
- 음식 배달 서비스보다 **여행 식탁 가이드**로 인식되도록 배달·속도 상징은 쓰지 않는다.

### 로고 모티프

- **그릇**: 한 끼, 포용, 사용자의 식이 기준을 안전하게 담는 그릇 → 화면의 '그릇 모양 타일'(위 16 / 아래 26 모서리)
- **숟가락**: 한스푼이라는 이름, 맛을 발견하는 첫 행동 → 장식 · 켜진 찜 하트에만 쓰는 주황

## 6. 컬러 시스템 (2026-11 새 테마 · 민트 프레시)

값의 원본은 「한스푼 디자인 시스템」 `tokens.json`이고, 코드에서는 `src/styles/theme.css`의 `--hs-*` 변수다. 흰 바탕, 민트 면, 로고 초록 버튼을 쓴다. 쌀빛(크림) 바탕은 더 이상 쓰지 않는다.

| 토큰 | 값 | 역할 |

| brand-700 | `#176B4D` | 주 버튼(판정 화면 밖), 선택된 입력 칩, 하단 내비 활성, 링크 |
| brand-800 | `#0F5038` | brand-700 누름 · 호버 |
| mint-100 / mint-200 | `#E2F6EC` / `#BFEBD5` | 탭 상단 영역, 직원 카드 바탕 / 민트 면 위 선 |
| mint-400 | `#3CCB8E` | 장식(버블 모션, 그릇 그림). 글자 금지 |
| orange-500 | `#F4773B` | 숟가락 포인트. 장식과 켜진 찜 하트에만. 글자 · 버튼 바탕 금지 |
| coral-100 / coral-700 | `#FFEDE5` / `#A8401A` | 켜진 하트 바탕, 한식 이야기 태그 |

| line-200 / line-300 / line-dash | `#E8EEEB` / `#D5DFDA` / `#C9D6CF` | 카드 테두리 / 외곽선 버튼 · 시트 손잡이 / 점선 상자 |
| surface-0 / surface-100 | `#FFFFFF` / `#F3F7F5` | 바탕 · 카드 / 옅은 면(설명 상자, 칩, 결과 상단) |

### 컬러 사용 규칙

1. **색은 뜻이 있을 때만.** 판정 결과 화면에서 색은 안전 · 주의 · 위험 · 확인 필요만 나타낸다. 헤더 · 식단 칩 · 근거 배지 · 버튼 · 링크는 무채색이고, 주 버튼은 `ink-900`이다. 예외는 찜 하트(코랄 · 주황) 하나다.
2. **색만으로 말하지 않는다.** 판정은 항상 글자 + 아이콘(✓ ! ✕ ?) + 색을 함께 쓴다.
3. 카드 안 설명 상자(판정 문장 포함)는 모두 연회색(`surface-100`) 바탕 + 검정 글자다. 판정색 바탕 · 판정색 글자를 쓰지 않는다.
4. 글자 대비 4.5:1, 아이콘 · 테두리 3:1 이상. `ink-400`, `orange-500`, `mint-400`은 글자에 쓰지 않는다.

### 판정 색상

각 상태는 `-500`(점 · 테두리 · 막대) · `-700`(글자) · `-100`(바탕) 세 단계다. 글자는 항상 `-700`.

| 상태 | 500 / 700 / 100 | 아이콘 | API |
| --- | --- | --- | --- |
| 안전 | `#18A058` / `#0B7344` / `#E4F7EC` | ✓ | `riskLevel` safe |
| 주의 | `#F0A000` / `#8A5300` / `#FFF3D6` | ! | caution + `evidenceBasis` estimated |
| 위험 | `#F0473C` / `#C0322B` / `#FFE9E7` | ✕ | danger |
| 확인 필요 | `#8A948F` / `#4F5B56` / `#EEF1EF` | ? | `riskLevel` null 또는 caution + `evidenceBasis` unknown |

확인 필요는 회청색에서 **회색**으로 바뀌었다. 브랜드 초록(`#176B4D`)과 안전 초록(`#18A058`)이 가까우므로 안전은 항상 ✓ 아이콘과 글자로 구분한다.

## 8. UI 스타일 원칙

### 형태

- 둥글게: 버튼 · 칩 · 배지 · 탭은 알약(`radius-pill`), 카드 26, 시트 위 모서리 32, 확인 창 26~30.
- **그릇 모양 타일**: 위 16 / 아래 26 모서리. 판정 타일, 아이콘 타일, 답 버튼.
- 탭 상단 영역: `mint-100` + 아래 두 모서리 56. 판정 결과 화면 상단은 `surface-100` + 44.
- 화면 좌우 여백 20, 카드 사이 10, 섹션 사이 24. 접힌 카드 안쪽 14, 펼친 카드 · 시트 안쪽 16.
- 모바일 최대 너비 430px, 화면 시안 폭 390.

### 깊이

- 그림자는 거의 쓰지 않는다. 회색 면 위 흰 카드에만 `shadow-card`, 붙어 있는 필터 줄에 `shadow-sticky`, 내 식단 보여주기 큰 카드에 `shadow-float`.
- 시트 · 확인 창 뒤는 `scrim`(`rgba(23,32,28,0.45)`).

### 아이콘

- 선 아이콘 한 벌: 24 viewBox, 선 2.2, 둥근 끝. 코드에서는 lucide-react를 `strokeWidth={2.2}`로 쓴다.
- 기본 20px, 작은 곳 14~16px, 판정 타일 안 24px(선 3).
- 뜻을 짐작해야 하는 동작은 아이콘만 두지 않고 글자를 붙인다(예: [메뉴판 사진] [기록 수정]).
- ✓ · ✕는 판정 상태(배지 · 타일)에만. '있음 · 없음' 같은 글자 옆에는 붙이지 않는다.

### 사진

- 촬영 · 앨범 사진은 미리보기 · 썸네일에서 잘리지 않게 전체 표시(contain)하고, 남는 영역은 어두운 바탕.
- 메뉴 · 가게 사진 데이터는 API에 없다. 메뉴에는 판정 타일을 쓴다.

### 모션

- 기본 전환 160–240ms. 랜딩 버블 · 분석 중 스캔 라인은 `prefers-reduced-motion`이면 멈춘다.
- 안전 상태나 오류에는 튀는 애니메이션을 쓰지 않는다.

## 9. 다국어·접근성 원칙

- 지원하는 7개 언어에서 버튼과 카드가 번역문 길이에 따라 자연스럽게 늘어나야 한다.
- `lang` 속성에 따라 언어별 서체를 적용하고, 중국어 간체와 번체를 서로 다른 로케일과 폰트로 구분한다.
- 아랍어 선택 시 문서 방향과 주요 레이아웃을 RTL로 전환한다.
- 아랍어는 글자의 상·하단이 잘리지 않도록 충분한 행간을 확보한다.
- 스페인어의 악센트 문자 및 구두점이 정상적으로 표시되는지 확인한다.
- 줄바꿈 규칙은 한국어·중국어·일본어와 공백 기반 언어의 차이를 고려해 언어별로 검증한다.
- 본문과 배경의 명도 대비는 WCAG AA를 충족한다.
- 터치 영역은 최소 44×44px을 확보한다.
- 위험 상태는 색상뿐 아니라 아이콘, 제목, 이유 문장으로 중복 전달한다.
- 핵심 행동에는 아이콘만 두지 않고 접근 가능한 이름을 제공한다.

## 10. 차별화 기준

배달의민족에서 참고하는 것은 특정 색상·서체·캐릭터가 아니라 다음의 경험 원칙이다.

- 짧고 사람다운 문장
- 음식에 대한 호기심을 자극하는 표현
- 둥글고 친근하지만 명확한 인터페이스
- 기능을 설명하기보다 사용자가 얻는 즐거움을 먼저 보여주는 구성

한스푼은 여기에 **식이 안전, 다국어 이해, 문화적 배려**를 결합해 독자적인 브랜드로 발전시킨다.
