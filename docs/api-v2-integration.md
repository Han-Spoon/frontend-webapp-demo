# 2026-11-23 운영 기능 가용성 변경

사용자 결정에 따라 운영에서 저장 음식·후기는 준비 중 안내와 비활성화로 전환했다. `/saved-menus`, `/reviews/me`, `/stores/{storeId}/reviews`, `/exchange-rates`의 배포 404가 근거다. `src/app/featureAvailability.ts`가 요청과 진입을 제어하고 API 어댑터는 보존한다. 환율은 고정 참고값임을 외화 환산시에만 안내한다. 서버 API 완료로 상태를 올리지 않는다. 상세 수정·검증은 [회의 보고](meeting-report-2026-11-23.md)를 참조한다.
