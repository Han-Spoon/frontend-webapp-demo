# 변경 기록

## 2026-11-21 — 전체 화면 지도: 가게 목록 시트·카드 넘기기

- 하단 탭의 지도(`/map`)를 아래 탭 바 없는 전체 화면으로. 뒤로 버튼은 이전 화면, 직접 연 경우 홈.
- 시연 지도도 같은 전체 지도로 교체(지역 태그·목록·카드 넘기기·정렬·음식 종류). 지도는 시연용 위치 개요 그대로이며 핀·안내 칩을 검색창과 카드 사이에만 배치. 가상 식당은 `demo/mapDemoStores.ts`에서 후보 형식으로 변환(반경 1.5km, 인증 먼저·가까운 순, 최대 20). 카드에 입점·레시피 인증 배지와 [내 프로필로 메뉴 보기]. 상세 시트는 기존 것, 상세의 하트 저장은 카드 북마크로 통일해 제거.
- 운영 지도의 하단 단일 카드를 목록 시트로 교체(접힘 150px/펼침 시 위쪽 검색창·지역 태그는 보이게, 손잡이 끌기·누르기, 펼치면 [지도 보기]). 이름 검색을 시작하면 펼침.
- 이름표를 누르면 단일 카드, 옆으로 넘길 때마다 넘긴 가게로 핀 선택·지도 중심 이동. 같은 건물 가게는 이웃 순서. 카드 위 왼쪽 끝 원형 목록 버튼으로 복귀.
- 검색창 바로 아래 가로 스크롤 지역 태그: 명동·남대문, 종로·광화문, 을지로·동대문, 홍대·연남, 이태원·한남, 용산, 성수·건대, 강남역, 신사·압구정, 코엑스·삼성, 잠실, 여의도(외국인 방문이 많은 동네 기준, 행정구 아님). 누르면 그 지역 중심에서 후보 조회(이름 검색 중이면 검색어 지움), 지금 결과의 지역은 강조. 중심 좌표는 대략값(`discovery/seoulAreas.ts`).
- 지도를 옮겨도 자동 재조회하지 않음. 목록 바로 위 가운데 [이 지역에서 검색](옮긴 뒤에만), 오른쪽 [내 주변]. 위쪽 '내 위치' 버튼 제거.
- 핀·이름표 다시 디자인(네이버지도·캐치테이블 배치 참고, 아이콘·색은 우리 토큰): 초록 원형 핀 + 아래 이름(흰 테두리 글자, 두 줄까지), 묶음은 핀 안 숫자, 선택은 주황 말풍선과 꼬리. 충돌 계산도 이 배치 기준.
- 목록 맨 위: 제목 줄("현재 위치 주변 · N") 없음. 정렬 버튼 하나 + 드롭다운(기본순·거리순·리뷰 많은순, 기본은 서버 순서), 가로 스크롤 음식 종류 버튼(그림 문자 + 한식·국·탕·찌개·고기·횟집·해물·국수·냉면·분식·중식·일식·양식·기타 중 결과에 있는 것). 분류는 이름 문자열이 아닌 업종 코드(`categoryCode`) 표 기준이며, 실제 값 21종(상가정보 소분류 15 + LOCALDATA 중분류·대분류 6)에 맞춤. 표에 없는 코드는 기타. 음식 종류는 지도 핀·카드에도 적용. 카드의 분류도 같은 짧은 이름(7개 언어), 기타는 한국어 화면에서만 원래 분류 이름. 분식 영어는 'Street food'(Snacks는 과자로 읽혀 제외).
- 접힌 목록은 `inert`(화면 밖 카드에 키보드 초점이 들어가 화면이 밀리는 문제 방지).
- 가게 카드: 가게명 → 후기 상세 시트, 별점(후기 수) 또는 후기 수, 구·분류·층, 내 위치/지도 중심에서 거리, 운영시간, 사진, 저장, [이 식당 메뉴 스캔].
- 후보 API에 없는 별점·운영시간·사진·층은 값이 없으면 숨김. `/dev/map-preview`에서만 가짜 값(사진은 실제 가게 사진 아님). 저장은 `localStorage`(`han-spoon-saved-stores`), 저장 API 없음.
- 새 문구는 컴포넌트 안에 7개 언어 임시 번역.
- `/dev/map-preview`를 개발 서버에서만 지연 로드. 1차 커밋에서 가상 가게 데이터가 운영 번들에 섞이던 문제 수정.
- 번들: JS 802.53kB → 820.09kB(gzip 277.85kB), CSS 131.81kB → 133.05kB.

## 2026-11-21 — 지도 마커 겹침 1차(같은 건물 묶음·이름표 충돌)

- `StoreMap` 내부만 변경, 사용 화면 5곳·`DemoStoreMap` 변경 없음, 클러스터링 라이브러리 미사용.

- 개발 서버 전용 `/dev/map-preview`(용산 밀집을 흉내 낸 가상 37곳, 좌표는 실제 위치 아님). 운영 번들에는 포함되지 않음.
- 번들: JS 798.66kB → 802.53kB.

## 2026-11-21 — 식단 없는 사용자 안내와 프로필 미확인 시 판정 표시

- 프로필을 불러오지 못하면(`null`) 결과 화면이 '식단 없음'으로 보고 서버의 위험·주의 배지를 숨기던 문제 수정(FN). 판정은 받은 그대로 보여 주고 식단 칸에 "내 식단 정보를 불러오지 못했어요. … 먹기 전에 직원에게 재료를 확인하세요." (UX-08)
- 식단 조건이 없을 때(「해당 없음」) 배지는 숨기면서 필터에는 "안전 6"이 보이던 문제 수정. 필터를 숨기고, 부제 "메뉴 n개의 재료를 정리했어요.", 식단 칸에 이유와 [식단 설정하기](온보딩 식단 단계), 안내 줄은 "재료는 매장에 꼭 확인하세요."만. 위험·주의 판정이 하나라도 있으면 배지·필터를 숨기지 않음.
- 홈: 식단 조건이 없는 사용자에게 "아직 식단 조건이 없어요 / 식단을 설정하면 메뉴마다 위험·주의를 알려 드려요." 카드와 [식단 설정하기]. 닫으면 이 기기에서 다시 보이지 않음(`localStorage`). 프로필을 아직 모르면 보이지 않음.
- 새 문구는 7개 언어 임시 번역.

## 2026-11-21 — 시트·확인창 접근성 통일

- 손으로 만든 모달 8곳이 Esc로 닫히지 않고, 초점이 뒤 화면으로 빠져나가고, 뒤 화면이 스크롤되던 문제 수정. (UX-14, T-12)
  - 확인창 5곳(기록 삭제, 후기 삭제, 로그아웃, 회원 탈퇴, 분석 취소) → 공용 `ConfirmDialog`. 처음 초점은 취소 버튼, 처리 중에는 닫히지 않음.
  - 하단 시트 3곳(재료 확인·빼고 요청, 내 식단 전달, 카드 팝업) → 공용 `ModalSheet`. 머리 영역·내용·애니메이션은 그대로.
- Radix 모달을 닫으면 초점이 연 버튼이 아니라 body로 가던 문제 수정(`useReturnFocus`). 식당 선택·기록 저장 시트, 후기 작성 시트에도 적용.
- 후기 삭제 실패 알림이 확인창 뒤에 가려지던 것을 확인창 안에 표시. 로그아웃·탈퇴 버튼 두 번 누르기 방지.
- 확인창 모양 통일: 테두리 버튼 2개, 위험 동작은 빨간 테두리. 로그아웃 확인 버튼은 채운 초록에서 초록 테두리로, 탈퇴 확인 버튼은 채운 빨강에서 빨간 테두리로 바뀜. 카드 팝업 뒤 배경 농도 55% → 45%.

## 2026-11-21 — 기록·카드의 실패 알림과 빈 상태

- 기록 열기·삭제가 실패하면 `console.error`만 남고 화면에 아무 변화가 없던 문제 수정. 그 기록 아래에 "기록을 열지/삭제하지 못했어요" 알림, 여는 동안 버튼 비활성. (UX-12)
- 서버 기록 목록을 불러오지 못하면 빈 목록이 되어 "첫 번째 메뉴를 기록해 보세요"가 보이던 문제 수정. 기록 화면·마이페이지 스캔 탭에 "기록을 불러오지 못했어요" + 다시 시도. 기기 저장 기록은 그 아래에 그대로 표시.
- 기록 삭제 전에 확인창("이 기록을 삭제할까요? 삭제하면 되돌릴 수 없어요.") 추가. Esc·바깥 누르기로 닫힘, 처음 초점은 취소.
- 기록 카드에 `메뉴 n개`·`위험 n`·`주의 n` 칩. 서버의 `dangerCount`·`cautionCount`를 쓰고, 기기 저장 기록은 메뉴로 직접 셈. 값이 없으면 0으로 채우지 않고 칩을 숨김(이전에는 `dangerCount`를 0으로 채웠음). (UX-20)
- 저장 카드 영역에 "저장한 카드" 제목, 빈 상태 설명과 [메뉴 스캔하기] 버튼. 마이페이지 스캔 탭 빈 상태에도 같은 버튼. (UX-21)
- 새 문구는 7개 언어 임시 번역. `메뉴 스캔하기`의 빠진 언어(중국어 간체·일본어·스페인어) 보충.
